📚 API de Livros

API desenvolvida em Python para gerenciamento de livros, utilizando MySQL como banco de dados.

O projeto foi desenvolvido como parte da avaliação da disciplina de SW II, ministrada pelo professor Anderson Vanin.

📝 Sobre o projeto

A API permite realizar o gerenciamento de livros, possibilitando:

Cadastrar livros;
Consultar livros;
Atualizar informações dos livros;
Excluir livros.

Os dados são armazenados em um banco de dados MySQL e a comunicação com a API é realizada através de requisições HTTP.

🛠️ Tecnologias utilizadas
Python
MySQL
API REST
Git/GitHub
🚀 Como executar

Clone o repositório:

git clone URL_DO_REPOSITORIO


Entre na pasta do projeto:

cd api-livros


Instale as dependências:

pip install -r requirements.txt


Configure a conexão com o banco de dados MySQL e depois execute a aplicação:

python app.py

🔗 Operações da API

A API possui operações para:

Método	Função
GET	Listar e consultar livros
POST	Cadastrar um livro
PUT	Atualizar um livro
DELETE	Excluir um livro
